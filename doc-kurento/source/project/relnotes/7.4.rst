======================================
Kurento 7.4 Release Notes (UNRELEASED)
======================================

This document tracks changes planned for the next Kurento release.

To install Kurento Media Server: :doc:`/user/installation`.

.. contents:: Table of Contents



Added
=====

* **MoQ streaming endpoints**. Kurento now provides ``MoqPublisherEndpoint``
  and ``MoqSubscriberEndpoint`` to publish media to and receive media from a
  Media over QUIC relay. The endpoints use the ``moq-gst`` GStreamer plugin.
  See :doc:`/features/moq_streaming` for setup and usage details, and the
  :doc:`browser tutorial </tutorials/js/tutorial-moq-relay>` for a working
  WebRTC-to-MoQ relay example.
