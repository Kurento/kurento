Tutorial: WebRTC ↔ MoQ relay bridge

This browser-only demo uses WebRtcEndpoint, MoqPublisherEndpoint, and MoqSubscriberEndpoint to publish a local WebRTC stream to a MoQ relay and subscribe back from the relay into the browser.
